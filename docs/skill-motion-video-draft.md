# Motion & Video — procédures

## When to Use
Générer une vidéo depuis un texte ou une idée ; transformer une image en animation ; vidéo publicitaire, promotionnelle, explicative ; animation de logo ; motion design, transitions, effets ; vidéos TikTok/YouTube/Instagram ; sous-titres, voix off, musique ; monter, améliorer ou convertir une vidéo existante ; générer des variantes.

## Stack
- Motion design / vidéos animées : Remotion (code React).
- Montage, conversion, sous-titres : FFmpeg.
- Animations éducatives : Manim.
- Voix off : synthèse vocale Hermes. Musique : Suno si accès, sinon libres de droits.
- Générateurs IA payants (Sora, Runway…) : seulement si l'utilisateur fournit l'accès.
- Jamais prétendre disposer d'un outil absent.

## Avant de commencer
Rassembler : objectif, public, scénario/message, durée, style (réaliste, cartoon, anime, 2D, 3D, motion design), format (9:16, 16:9, 1:1), couleurs/logo, ressources fournies, langue/ton, plateforme de destination. Poser les questions ciblées pour ce qui manque ; proposer des défauts pour le reste.

## Workflow
1. **Analyser** : objectif, public, scénario, durée, style, format. Demander les précisions indispensables.
2. **Concevoir** : script, scènes, storyboard, mouvements, transitions, textes, ambiance sonore.
3. **Créer les ressources** : images, éléments graphiques, voix off, sons.
4. **Générer et assembler** : séquences, animations, montage, synchro son, sous-titres, effets.
5. **Tester et livrer** : vérifier rendu, fluidité, cohérence, son, durée, format ; corriger ; exporter ; fournir le fichier final + éléments complémentaires.

## Human gate — s'arrêter et demander l'humain
- Choix artistique ou scénaristique important non déductible de la demande ; concepts très différents possibles.
- Résultat généré éloigné de la vision de l'utilisateur.
- Reproduction d'un visage ou d'une voix réelle ; ressource protégée ou licence à valider.
- Paiement, abonnement, crédits payants.
- Publication ou envoi externe ; suppression de fichiers ; action irréversible.
- Contraintes techniques empêchant le résultat demandé.
Avant de s'arrêter : expliquer le blocage, préciser ce qui est nécessaire, proposer une solution réaliste.

## Comportement en cas d'échec
- Identifier la cause : prompt imprécis, fichier corrompu, outil indisponible, erreur de rendu, audio, format.
- Vérifier messages d'erreur et paramètres de génération/export.
- Simplifier ou reformuler le prompt ; régénérer seulement les séquences nécessaires.
- Contrôler la cohérence visuelle et sonore après chaque correction importante.
- Préserver les versions précédentes et fichiers sources ; éviter les générations payantes répétées sans autorisation.
- Si persiste : expliquer ce qui a échoué, les tentatives, les résultats obtenus, les alternatives.
- Ne jamais prétendre une vidéo générée, rendue ou exportée sans vérification réelle.

## Critères de fin (tous requis)
- La vidéo correspond à l'objectif, au scénario et aux exigences.
- Style, couleurs, personnages, éléments graphiques cohérents entre les scènes.
- Animations fluides, transitions adaptées, textes lisibles et correctement orthographiés.
- Son, voix off et sous-titres synchronisés quand demandés.
- Durée, résolution, ratio et format d'export respectent les specs ; le fichier s'ouvre et se lit.
- Défauts majeurs corrigés ou clairement signalés ; ressources sous licences valides.
- Fichier final + instructions fournis ; limites restantes mentionnées.

## Preuves à fournir à chaque livraison
- Le fichier vidéo final, avec nom, format, durée, résolution, ratio.
- Aperçu ou captures représentatives du rendu.
- Script, storyboard ou prompt final utilisé quand pertinent.
- Fichiers sources et ressources complémentaires disponibles.
- Résultats des vérifications techniques (lecture, image, animation, audio, sous-titres, synchro).
- Erreurs, limitations et corrections restantes ; licences des ressources externes.
- Lien ou emplacement du fichier final uniquement s'il est réellement accessible.
- Distinguer clairement : généré / exporté / testé / restant à vérifier.
